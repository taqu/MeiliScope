# キーボードショートカット

---

## グローバルナビゲーション

| ショートカット | 操作 |
|---|---|
| **Ctrl+1** | Index Explorer に切り替え |
| **Ctrl+2** | Document Browser に切り替え |
| **Ctrl+3** | Query Console に切り替え |
| **Ctrl+Shift+C** | 接続パネルを開く / 閉じる |

---

## Query Console

| ショートカット | 操作 |
|---|---|
| **Ctrl+Enter** | 検索を実行 |
| **Ctrl+S** | Saved Queries パネルの表示切り替え |
| **Shift+Alt+F** | JSON をフォーマット（整形） |

---

## 注意事項

- テキスト入力を伴うショートカット（Shift+Alt+F など）は、テキストエディターや入力フィールドにカーソルがある場合は無効になります（エディター内で動作するよう設計されたショートカットを除く）。
- **Ctrl+S**（Saved Queries）はエディターにフォーカスがある場合でも Query Console ビュー内でグローバルに動作します。
