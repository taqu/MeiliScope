# 接続管理

MeiliScope では複数の Meilisearch サーバーへの接続を保存・切り替えできます。

---

## 接続パネルを開く

**Ctrl+Shift+C** を押すか、上部バーの **Connections** ボタンをクリックします。

---

## 接続を追加する

1. **Add connection** をクリックします。
2. 以下を入力します:
   - **Name** — この接続の表示名（例: "ローカル開発", "本番"）
   - **URL** — スキームとポートを含む Meilisearch サーバー URL（例: `http://localhost:7700`）
   - **API Key** — オープンインスタンスの場合は空白のまま。マスターキー、管理キー、または検索専用キーを使用します。
3. **Connect** をクリックします。MeiliScope は URL と資格情報をすぐに確認します。

---

## 接続を切り替える

保存された接続をクリックしてアクティブな接続に設定します。Index Explorer が自動的に再読み込みされます。

---

## API キーの要件

| 機能 | 最低限必要な権限 |
|---|---|
| ヘルスチェック | なし |
| インデックス一覧 | インデックス読み取り |
| ドキュメント参照 | ドキュメント読み取り |
| 検索 | 検索 |
| ドキュメントの作成・更新・削除 | ドキュメント書き込み |
| タスク追跡 | タスク読み取り |

**検索専用キー**はブラウズと検索に十分です。ドキュメント編集にはドキュメント書き込みとタスク読み取り権限を持つキーが必要です。

インデックスの列挙が HTTP 403 で失敗した場合、MeiliScope は接続を **limited access** モードに設定し、インデックス UID を直接入力するフィールドを表示します。

---

## 資格情報のストレージ

API キーは OS のキーチェーンに保存され、設定ファイルやログファイルには書き込まれません。

| プラットフォーム | バックエンド |
|---|---|
| Windows | Windows 資格情報マネージャー |
| Linux | Secret Service（GNOME Keyring / KWallet） |
| フォールバック | セッション専用（プロセスメモリ） |

セッション専用モードでは、終了時に資格情報が失われます。このモードが有効な場合、接続パネルに警告が表示されます。
