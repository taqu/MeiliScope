# クイックスタート

初回起動から最初の検索結果を得るまでの基本的な手順を説明します。

---

## 1. MeiliScope を起動する

**Windows:** `meiliscope.exe` を実行します。

**Linux:** ターミナルを開き `./meiliscope` を実行します。

メインウィンドウが開き、左側にインデックスエクスプローラー、右側にコンテンツエリアが表示されます。

---

## 2. 接続を追加する

1. **Ctrl+Shift+C** を押すか、上部バーの **Connections** ボタンをクリックします。
2. **Add connection** をクリックします。
3. 表示名、サーバー URL（例: `http://localhost:7700`）、および Meilisearch インスタンスで必要な API キーを入力します。
4. **Connect** をクリックします。

MeiliScope は URL と資格情報をすぐに確認します。接続が成功すると緑色のインジケーターが表示されます。

> **注意:** 検索専用キーでもブラウズおよび検索が可能です。ドキュメントの編集やインデックス一覧の取得には適切な権限を持つキーが必要です。インデックスの列挙が HTTP 403 でブロックされた場合、MeiliScope はインデックス UID を手動入力するフィールドを表示します。

---

## 3. インデックスを参照する

接続後、利用可能なインデックスが **Index Explorer** パネル（Ctrl+1）に表示されます。

インデックス名をクリックして選択します。右側のパネルには統計情報（ドキュメント数、フィールド分布など）が表示されます。

---

## 4. ドキュメントを参照する

**Document Browser** タブ（Ctrl+2）に切り替えると、選択したインデックスのドキュメントをページ単位で表示できます。

- **Previous** / **Next** ボタンでページを切り替えます。
- 任意の行をクリックするとその行の **JSON Inspector** が開きます。
- **Export** ボタンで現在のページを JSON または CSV として保存できます。

---

## 5. ドキュメントを詳しく確認する

**JSON Inspector** はドキュメント全体を折りたたみ可能なツリーとして表示します。開示矢印をクリックするとネストされたオブジェクトや配列を展開できます。

---

## 6. 検索クエリを実行する

**Query Console** タブ（Ctrl+3）に切り替えます。

デフォルトのクエリは `{}` で、全ドキュメントを返します。

キーワードで検索するには:
```json
{
  "q": "コーヒー"
}
```

**Search** をクリックするか **Ctrl+Enter** を押して実行します。

結果は総ヒット数と処理時間とともにエディタの下に表示されます。

---

## 7. Search Builder を使う

Query Console ツールバーの **Builder** トグルをクリックすると、フォームベースの **Search Builder** に切り替わります。

フィルター、ソート、ファセット、ページネーションなどをフォームで設定できます。JSON を書く必要はありません。

---

## 8. クエリを保存する

Query Console ツールバーの **★ Saved** をクリックして **Saved Queries** パネルを開きます。

名前を入力して **Save** をクリックします。保存されたクエリはローカルに保存され、セッションをまたいで保持されます。
