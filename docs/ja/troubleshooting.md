# トラブルシューティング

詳細なトラブルシューティング情報は[英語版](../en/troubleshooting.md)を参照してください。

---

## 接続の問題

**「接続に失敗しました」またはタイムアウト**
- Meilisearch サーバーが起動しており、このマシンからアクセス可能であることを確認してください。
- URL のスキーム、ホスト、ポートが正しいことを確認してください。
- ログファイルで詳細なエラーを確認してください:
  - Windows: `%AppData%\MeiliScope\logs\`
  - Linux: `~/.local/share/MeiliScope/logs/`

**「Unauthorized」または「Forbidden」**
- API キーが正しいか確認してください。
- 検索専用キーを使用している場合、一部の機能（インデックス一覧、ドキュメント編集）は利用できません。これは正常な動作です。

**インデックス一覧が空 / 「インデックス UID を手動入力」**
- API キーにインデックスの一覧取得権限がありません。表示されるテキストフィールドにインデックス UID を直接入力してください。

## 起動の問題

**Windows: 白いウィンドウが表示される**
WebView2 の初期化に問題があります。Windows Update で WebView2 を更新してください。

**Linux: 「共有オブジェクトファイルを開けません」**
必要なランタイムライブラリをインストールしてください（[インストール — Linux](getting-started/installation.md#linux) を参照）。

---

## 検索の問題

**クエリに結果が返らない**
- JSON が有効であることを確認してください。
- フィルターがインデックス設定でフィルタリング可能な属性を参照しているか確認してください。
- カスタムパラメーターを一つずつ削除して原因を特定してください。

---

## ログファイル

| プラットフォーム | パス |
|---|---|
| Windows | `%AppData%\MeiliScope\logs\` |
| Linux | `~/.local/share/MeiliScope/logs\` |

ログファイルには API キーや認証ヘッダーは含まれません。
