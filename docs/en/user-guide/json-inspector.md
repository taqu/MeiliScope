# JSON Inspector

The JSON Inspector provides an interactive collapsible view of a Meilisearch document.

---

## Opening a Document

- In the **Document Browser**: click any row.
- In the **Query Console**: click any result row.

---

## Navigation

- Click the **▶** arrow next to an object or array to expand it.
- Click **▼** to collapse.
- Deeply nested structures can be expanded level by level.

---

## Viewing Raw JSON

The raw document JSON is preserved as returned by Meilisearch. Numbers are not truncated or rounded — the inspector uses the exact bytes from the response.

---

## Editing a Document

From the JSON Inspector, click **Edit** to open the Document Editor. See [Document Editing](document-editing.md) for details.
