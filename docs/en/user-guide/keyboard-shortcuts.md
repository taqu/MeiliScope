# Keyboard Shortcuts

---

## Global Navigation

| Shortcut | Action |
|---|---|
| **Ctrl+1** | Switch to Index Explorer |
| **Ctrl+2** | Switch to Document Browser |
| **Ctrl+3** | Switch to Query Console |
| **Ctrl+Shift+C** | Open / close Connections panel |

---

## Query Console

| Shortcut | Action |
|---|---|
| **Ctrl+Enter** | Execute search |
| **Ctrl+S** | Toggle Saved Queries panel |
| **Shift+Alt+F** | Format JSON (pretty-print) |

---

## Notes

- Shortcuts that involve text input (such as Shift+Alt+F) are blocked when the cursor is inside a text editor or input field, with the exception of shortcuts explicitly designed to work in editors.
- **Ctrl+S** (Saved Queries) works globally within the Query Console view, including when the editor is focused.
